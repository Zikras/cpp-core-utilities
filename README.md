# C++ Core Utilities Suite 🚀

Welcome to my repository showcasing a collection of practical terminal-based applications built using modern C++. This project reflects my progress in mastering fundamental programming concepts, standard algorithms, logic structures, and secure user-input validation.

## 🛠️ Applications Included

### 1. Dynamic Matrix Calculator (`basic_calculations_calculator.cpp`)
* **Core Concept:** Control flows, edge-case validation, switch-case statements.
* **Features:** A robust basic arithmetic processor that explicitly shields against structural system calculation crashes like division-by-zero errors.

### 2. Expense Manager (`expense_manager.cpp`)
* **Core Concept:** Interactive input processing, dynamic data assignment.
* **Features:** A budget analyzer evaluating user-driven income/expenditure thresholds to calculate financial feasibility bounds accurately.

### 3. Movie Quality Classifier (`movie_rating.cpp`)
* **Core Concept:** Gapless multi-tiered logical ranges, array boundary logic.
* **Features:** An evaluation tool categorizing critical review scores into explicit quality classifications with precise floating-point tracking.

### 4. Dynamic Geometric Shape Solver (`the_dynamic_shape_calculation_tool.cpp`)
* **Core Concept:** Multi-type data casting, conditional branching, string matching.
* **Features:** Detects string matching keywords dynamically to evaluate unique spatial dimensions selectively using custom standard mathematical algorithms.

### 5. Quick Optimum Finder (`max_of_three.cpp`)
* **Core Concept:** Modern C++11 initializer lists, STL optimization headers (`<algorithm>`).
* **Features:** Bypasses legacy messy conditional blocks to isolate optimal numeric values cleanly using optimized single-line functional evaluation.
